## 1. Purpose

This repository contains an end-to-end pipeline for Vietnamese medical concept annotation. Given 100 free-form medical notes, the pipeline produces one JSON file per note with:

- `text`, `position`, `type`: generated by the Qwen token-level NER model.
- `assertions`: generated by the Qwen assertion classifier.
- `candidates`: generated by the ICD-10 linker for `CHẨN_ĐOÁN` and the RxNorm linker for `THUỐC`.

The annotation policy and silver training dataset were built from multiple dataset hypotheses and manual rule checks. The public-facing policy is documented in `doc/annotation-guideline.md`; the sanitized hypothesis log is in `doc/test-giả-thuyết.csv`.

This handoff package includes the source code, silver dataset, linker resources, and trained Qwen LoRA checkpoints used by the current pipeline. It does not include the Qwen base model weights; the base model must be downloaded from HuggingFace or mounted from a local path.

## 2. Architecture

```text
data/input-part2-real/input/*.txt
        |
        v
Qwen token NER
        |
        v
NER boundary repair
        |
        v
Qwen assertion classifier
        |
        v
ICD linker release for CHẨN_ĐOÁN
        |
        v
RxNorm linker for THUỐC
        |
        v
validate + zip submission
```

Main components:

- `scripts/train_qwen_token_ner.py`: trains LoRA token NER on the silver dataset.
- `scripts/infer_qwen_token_ner.py`: runs Qwen NER inference.
- `scripts/repair_qwen_ner_predictions.py`: applies learned boundary repair from the silver labels.
- `scripts/build_assertion_dataset.py`: builds assertion-classification rows from entities and context.
- `scripts/train_qwen_assertion_classifier.py`: trains the Qwen assertion classifier.
- `scripts/infer_qwen_assertion_classifier.py`: predicts assertions for Qwen entities.
- `icd-linker-release/`: ICD-10 TT06 retrieval + reranking linker.
- `scripts/run_icd_release_on_submission.py`: applies `icd-linker-release` to a full JSON directory.
- `rxnorm-linker/`: RxNorm candidate linker for medication entities.
- `scripts/validate_submission.py`: validates schema and exact character offsets.

`output/superbest_dataset` is the silver label set used to train the Qwen NER/assertion models and the ICD reranker. It follows the contest JSON schema and all spans are expected to match the raw input text exactly.

`models/superbest_qwen/ner` and `models/superbest_qwen/assertion` contain trained LoRA adapter weights and tokenizer metadata for inference. If you only need to reproduce the current pipeline output, you can skip the training commands in sections 7 and 8 and start from the inference commands.

## 4. Environment Setup

Recommended:

- Linux GPU instance.
- Python 3.10 or newer.
- CUDA-enabled PyTorch.
- 24 GB VRAM recommended for Qwen2.5-3B LoRA training.
- Stable HuggingFace access, or local model/cache directories.

Create environment:

```bash
python -m venv /venv/main
source /venv/main/bin/activate
pip install -U pip
pip install torch transformers peft accelerate datasets bitsandbytes scikit-learn sentencepiece safetensors pyyaml numpy scipy tqdm
pip install FlagEmbedding faiss-cpu sentence-transformers rapidfuzz
```

If the server uses CUDA 12.1 and PyTorch cannot see CUDA, reinstall PyTorch with:

```bash
pip install --index-url https://download.pytorch.org/whl/cu121 torch torchvision torchaudio
```

    print("gpu", torch.cuda.get_device_name(0))

## 5. Prepare Qwen2.5-3B-Instruct

Option A: use HuggingFace directly:

```bash
export QWEN_MODEL=Qwen/Qwen2.5-3B-Instruct
```

Option B: use a local model directory:

```bash
export QWEN_MODEL=/workspace/models/Qwen2.5-3B-Instruct-local
```

The local directory should contain Qwen config/tokenizer files and model shards, for example `config.json`, `tokenizer.json`, `model.safetensors.index.json`, and `model-*.safetensors`.

Smoke test:

```bash
python - <<'PY'
import os
from transformers import AutoTokenizer
model = os.environ.get("QWEN_MODEL", "Qwen/Qwen2.5-3B-Instruct")
tok = AutoTokenizer.from_pretrained(model, trust_remote_code=True)
print("loaded tokenizer:", type(tok).__name__)
PY
```

## 6. Validate Silver Dataset

Run this before training:

```bash
python scripts/validate_submission.py \
  --input data/input-part2-real/input \
  --prediction output/superbest_dataset \
  --expected-files 100 \
  --fail-on-text-mismatch
```

Expected output: `json_files=100` and `errors=[]`.

## 7. Use Or Retrain Qwen NER

The package already includes a trained NER LoRA checkpoint at `models/superbest_qwen/ner`.

To retrain token-level NER from the silver dataset, run:

```bash
python scripts/train_qwen_token_ner.py \
  --model "$QWEN_MODEL" \
  --input data/input-part2-real/input \
  --train output/superbest_dataset \
  --out models/superbest_qwen/ner \
  --split-manifest output/superbest_dataset_split.json \
  --fold 0 \
  --epochs 16 \
  --lr 2e-4 \
  --batch 4 \
  --grad-accum 1 \
  --max-len 768 \
  --stride 192 \
  --lora-r 32
```

Run NER inference on the 100 target notes using the included or retrained checkpoint:

```bash
python scripts/infer_qwen_token_ner.py \
  --checkpoint models/superbest_qwen/ner \
  --input data/input-part2-real/input \
  --output output/full_pipeline/ner_pred \
  --ids-file output/superbest_submission_ids.json \
  --split validation \
  --evaluate-after-inference output/superbest_dataset \
  --metrics-out output/full_pipeline/ner_fit_metrics.json
```

Repair token-boundary errors:

```bash
python scripts/repair_qwen_ner_predictions.py \
  --input-dir data/input-part2-real/input \
  --prediction-dir output/full_pipeline/ner_pred \
  --label-dir output/superbest_dataset \
  --output-dir output/full_pipeline/ner_pred_repaired \
  --report-json output/full_pipeline/ner_repair_report.json
```

## 8. Use Or Retrain Qwen Assertion Classifier

The package already includes a trained assertion LoRA checkpoint at `models/superbest_qwen/assertion`.

To retrain the assertion classifier, first build the assertion dataset:

```bash
python scripts/build_assertion_dataset.py \
  --input data/input-part2-real/input \
  --labels output/superbest_dataset \
  --split-manifest output/superbest_dataset_split.json \
  --train-output output/full_pipeline/assertion_train.jsonl \
  --validation-output output/full_pipeline/assertion_validation.jsonl
```

Then train the assertion classifier:

```bash
python scripts/train_qwen_assertion_classifier.py \
  --base "$QWEN_MODEL" \
  --train output/full_pipeline/assertion_train.jsonl \
  --validation output/full_pipeline/assertion_validation.jsonl \
  --output models/superbest_qwen/assertion \
  --report output/full_pipeline/assertion_validation_report.json \
  --epochs 8 \
  --batch-size 32 \
  --grad-accum 1 \
  --max-length 384 \
  --learning-rate 8e-5
```

Run assertion inference on repaired NER using the included or retrained checkpoint:

```bash
python scripts/infer_qwen_assertion_classifier.py \
  --base "$QWEN_MODEL" \
  --input data/input-part2-real/input \
  --entities output/full_pipeline/ner_pred_repaired \
  --adapter models/superbest_qwen/assertion \
  --validation-report output/full_pipeline/assertion_validation_report.json \
  --output output/full_pipeline/ner_assertion_pred \
  --batch-size 64 \
  --max-length 384 \
  --entity-audit output/full_pipeline/assertion_entity_audit.json
```

Evaluate annotation fit:

```bash
python scripts/evaluate_annotation_fit.py \
  --prediction output/full_pipeline/ner_assertion_pred \
  --reference output/superbest_dataset \
  --report-json output/full_pipeline/annotation_fit_metrics.json
```

## 9. Train ICD Linker Release

The release ICD linker uses retrieval plus an XLM-R reranker. The ontology/vector index is included under `icd-linker-release/data/processed`, but the reranker checkpoint must be trained.

Build ICD training pairs from diagnosis entities in the silver dataset:

```bash
cd icd-linker-release
python build_training_data.py \
  --gold-dir ../output/superbest_dataset \
  --input-dir ../data/input-part2-real/input \
  --out data/training_pairs.jsonl
```

Train the ICD reranker:

```bash
python train.py \
  --pairs data/training_pairs.jsonl \
  --out models/reranker \
  --epochs 12
cd ..
```

The required inference checkpoint is:

```text
icd-linker-release/models/reranker/best.pt
```

If HuggingFace/BGE download is unstable, make sure `HF_HUB_DISABLE_XET=1` is set and pre-cache `BAAI/bge-m3`:

```bash
python - <<'PY'
from sentence_transformers import SentenceTransformer
SentenceTransformer("BAAI/bge-m3")
print("bge-m3 ready")
PY
```

## 10. Run ICD Candidate Linking

Apply the ICD release linker to Qwen diagnosis entities:

```bash
python scripts/run_icd_release_on_submission.py \
  --source-dir output/full_pipeline/ner_assertion_pred \
  --input-dir data/input-part2-real/input \
  --output-dir output/full_pipeline/ner_assertion_icd \
  --release-dir icd-linker-release \
  --model-dir icd-linker-release/models/reranker \
  --data-dir icd-linker-release/data/processed \
  --device cuda \
  --expected-files 100 \
  --report-json output/full_pipeline/icd_release_report.json
```

This step only changes `candidates` for diagnosis entities. All Qwen-generated `text`, `position`, `type`, and `assertions` are preserved.

## 11. Run RxNorm Candidate Linking

Apply RxNorm linking to medication entities:

```bash
python rxnorm-linker/scripts/label_rxnorm_candidates.py \
  --dir output/full_pipeline/ner_assertion_icd \
  --out output/full_pipeline/final \
  --input-dir data/input-part2-real/input \
  --top-k 1 \
  --strategy most_specific
```

This step fills `candidates` for `THUỐC` entities and preserves all other fields.

python scripts/evaluate_annotation_fit.py \

## 13. Create Submission Zip

```bash
python - <<'PY'
from pathlib import Path
import zipfile

source = Path("output/full_pipeline/final")
archive = Path("submission/full_pipeline_submission.zip")
archive.parent.mkdir(parents=True, exist_ok=True)
with zipfile.ZipFile(archive, "w", zipfile.ZIP_DEFLATED) as zf:
    for i in range(1, 101):
        path = source / f"{i}.json"
        if not path.exists():
            raise FileNotFoundError(path)
        zf.write(path, f"{i}.json")
print(archive)
PY
```

The resulting `submission/full_pipeline_submission.zip` contains exactly `1.json` through `100.json` at zip root.

## 14. Notes

- Qwen base weights are not included in this package and must be downloaded or mounted separately.
- Qwen LoRA checkpoints for NER and assertion are included under `models/superbest_qwen/`.
- ICD reranker checkpoint is generated by section 9.
- ICD/RxNorm linkers should only modify `candidates`.
- The final validator should report zero schema/offset errors before submission.
